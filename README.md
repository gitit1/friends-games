# 🌟 עולם החברים — משחקי חשיבה בעברית

אתר משחקים חינוכי בעברית — RTL מלא, מובייל־פירסט — לילדים צעירים:
**62 משחקים** ב־9 קטגוריות (מספרים, חשיבה, כיף, מוזיקה, יצירה, אותיות, אנגלית, ספורט וגדילה),
**100 "חברים"** צבעוניים שכל אחד מהם הוא מספר, עם קול עברי מוקלט, ומשחק תלת־ממד אחד (three.js).

🎮 **המשחקים באוויר:** https://assaf.gititregev.com

## עקרונות העיצוב

- **בלי כישלונות** — אין game over, אין טיימרים, אין תחרות; טעות מקבלת רמז עדין וממשיכים.
- **קושי מצטבר** — כל משחק נפתח קל ומסתיים ברמת "אלוף" שכוללת הכול, ובדיקה אוטומטית (`npm run check:champion`) שומרת שיכולת קיימת לא נעלמת בשדרוג.
- **רגוע לחושים** — צבעים מעומעמים, בלי הבזקים, אנימציה קצרה וקשורה לפעולת הילד, כיבוד reduced-motion.
- **טרום־קוראים** — הכול תמונות + הקראה בעברית (קול מוקלט + נפילה ל־TTS).
- **ארט אפוי, לא צורות CSS** — הסצנות והחפצים מרונדרים מראש עם טקסטורה ותאורה; CSS משמש ללייאאוט, טקסט ואנימציה.
- **עברית ואנגלית** — ממשק דו־לשוני עם שיקוף RTL/LTR מלא.
- **בקרת הורים** — רמות, טווח מספרים, פעולות חשבון, קול, מצב תנועה רגועה ועוד.

## טכנולוגיה

React 19 · TypeScript · Vite 8 · three.js (משחק התלת־ממד בלבד, בטעינה עצלה) · ללא ספריות UI ·
פריסה כ־Docker (בנייה ב־Node 22 והגשה ב־nginx).

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה לפרודקשן
```
